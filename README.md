# 🚀 Project Lone Rover: Astronaut Biometric Telemetry Dashboard

**Live Demo:** [View the Dashboard Here](https://abdulrabdev.github.io/Astronaut-Biometric-Telemetry-Dashboard/)

An offline-capable, interactive biometric telemetry dashboard and predictive health simulator tailored for deep space missions. Developed for the **NASA Space Apps Challenge**.

## ✨ Key Features
* **Interactive Bio-Scanner:** A clickable SVG human body mapping for targeted organ telemetry (Brain, Heart, Bones).
* **Live Telemetry Stream:** Real-time (1Hz) simulation of heart rate, blood pressure, and suit O₂ reserves.
* **Mission Scenario Engine:** Simulates physiological degradation over 12 months across varying gravity fields (Microgravity vs. Mars) and EVA exertion.
* **NASA HRP Integration:** Direct mapping to the 5 Spaceflight Hazards with actionable mitigation steps.
* **Autonomous Triage:** Built-in self-assessment tools, dynamic 30-day health trends, and automated flight-surgeon SBAR report generation.
* **Emergency Focus Mode:** High-contrast alerts triggered automatically during critical threshold breaches (e.g., HR > 120 BPM).

## 🛠️ Tech Stack
* **100% Vanilla JavaScript** (Zero external dependencies)
* **HTML5 & CSS3** (Custom animations and progressive disclosure UI)
* **Fully Offline-Capable** (LocalStorage data persistence)

## 🚀 How to Run Locally
Simply clone the repository and open `index.html` in any modern web browser. No local server, build tools, or internet connection are required to run the simulation.
